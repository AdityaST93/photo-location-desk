# 📍 Photo Location Desk

A simple, browser-based tool to organize and manage photo locations in one place.

## 🌟 Live Demo

🚀 **Try it here:** https://adityast93.github.io/photo-location-desk/

## 📖 About the Project

Photo Location Desk is a lightweight web application designed to help users organize and manage locations associated with their photos. It provides a simple interface that can be accessed directly through a web browser.

## ✨ Features

- 📌 Add and manage photo locations.
- 🗂️ Organize location information in one place.
- 🌐 Access the application through a web browser.
- 💻 Simple and lightweight interface.
- 🔗 Live website hosted using GitHub Pages.

## 🚀 How to Use

1. Open the live website using the link above.
2. Add and manage your photo locations using the application.
3. Keep your location information organized.

## 💻 Run Locally

You can run this project on your computer by following these steps:

**1. Clone the repository**

```bash
git clone https://github.com/AdityaST93/photo-location-desk.git
```

**2. Open the project folder**

```bash
cd photo-location-desk
```

**3. Run the application**

Open the `index.html` file in your preferred web browser.

No additional installation is required for a basic HTML project.
